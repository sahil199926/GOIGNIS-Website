# GoIGNIS — Engineering, connected.

A single-page homepage concept built with Vite, vanilla JavaScript, Three.js, and GSAP.

## Run

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to any static web host.

## Experience

- Two real-time Three.js architectural models, with drag rotation, animated system flows, an exploded view, and five selectable engineering disciplines.
- System isolation, keyboard-accessible discipline tabs, scroll reveals, interactive process steps, live New York/India clocks, FAQ accordions, responsive navigation, and a project enquiry dialog.
- The enquiry form prepares a mailto draft. It does not send or store submissions. A copyable draft is available as a fallback.
- Reduced-motion support, restrained device pixel ratio, off-screen render suspension, native dialog keyboard handling, and a WebGL fallback.
- No fabricated client logos, project portfolio, testimonials, or quantitative performance claims. Building geometry is an illustrative concept, not a construction design or an actual GoIGNIS project.

The process section describes a proposed collaboration journey, rather than a contractual service commitment. Google Fonts supplies DM Sans and Manrope, with local sans-serif fallbacks. No backend or external analytics are included.

## Interaction refinement

System selection crossfades the engineering networks, eases into a small zoom, and gently turns the model; rapid changes replace the previous animation. An animated SVG service riser runs down the page gutter and changes color and flow pattern with the selected discipline. Mobile navigation uses a staggered entrance, an animated hamburger, Escape/outside-click dismissal, and inert hidden links. All four process cards have flowing circuit illustrations on hover, keyboard focus, and touch selection. FAQ answers animate their measured height in both directions and can reverse mid-animation. Reduced-motion preferences suppress decorative motion.

## Connected equipment footer

The enlarged footer receives the page-wide pipe at a measured SVG inlet. Five illustrative animated equipment diagrams correspond to the selected discipline: fire pump, fire alarm control panel, electrical distribution panel, air handling unit, and ARCS/BDA radio cabinet. The footer selector updates the building, page route, and equipment together. These are conceptual system illustrations, not product specifications.

Fire Alarm, Electrical, and ARCS/BDA illustrations now use distinct connected device layouts: a detector/notification loop and red alarm panel, switchgear with separate busbars and a cable gland, and a finned BDA amplifier with donor/indoor antennas and threaded coax fittings. Visible cable paths terminate at equipment entries. Illustrations remain conceptual, not wiring or installation instructions.
